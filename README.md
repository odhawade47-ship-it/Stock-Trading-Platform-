# To-Do List (localStorage)

A small, single-page To‑Do list web application that stores tasks locally in the browser using localStorage. Open `todo/index.html` in any modern browser to run the app — no server required.

Features
- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks completed
- Clear completed tasks
- Filter: All / Active / Completed
- Persistent across reloads via localStorage

How to use
1. Download or clone the repository.
2. Open todo/index.html in your browser (double-click or `File > Open`).
